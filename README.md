# 🏠 House Price Predictor

A Machine Learning web application that predicts residential house prices based on property features. The application is built using **Streamlit** and trained on the **Kaggle Ames Housing Dataset**, allowing users to estimate house prices through an interactive interface.

---

# 🚀 Features

- Predict house prices instantly
- Interactive Streamlit interface
- Data preprocessing and feature engineering
- Multiple regression models evaluated
- Model serialization using Joblib
- Real-time predictions

---

# 📊 Dataset

**House Prices - Advanced Regression Techniques**

Source:
https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques

The dataset contains residential housing information including:

- Overall Quality
- Living Area
- Garage Capacity
- Basement Area
- Lot Area
- Year Built
- Bathrooms
- Bedrooms
- Sale Price (Target)

# 📈 Model Evaluation

Models evaluated:

- Linear Regression
- Ridge Regression
- Lasso Regression
- Random Forest Regressor

Evaluation Metrics:

- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

The best-performing model was selected for deployment.

# ▶️ Installation

Clone the repository

```bash
git clone https://github.com/Yash-1-bhardwaj/housepredicter.git
```

Move into the project

```bash
cd housepredicter
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run Streamlit

```bash
streamlit run app.py
```

The application will open in your browser automatically.
